# 五个可直接理解的业务场景

## 1. 网站 / App 的 AI 新闻栏目

你的产品负责展示，ScopeAI 提供本站公开新闻摘要、配图、正文及出处。读取列表用于卡片，用户点开时再取详情。先查分类或专题，再选择你需要的数据范围。

使用 `/news/articles`、`/news/articles/{id}`、`/news/topics`。列表和详情分别计费，不因获得一页摘要就拿到全站无限读取权限。

## 2. 企业内部 AI 日报

你的程序每天按日期与关键词读取新闻，再由你自己的逻辑整理日报。ScopeAI 提供新闻数据；发送邮件、企业聊天消息或额外 AI 写作由你的系统完成，不包含在新闻读取费用中。

使用 `/news/search` 和 `/news/articles`。示例：每天 100 条摘要分两页读取，按首版价目共 0.02 元。

## 3. 持续更新的行业资料库

从 `/news/changes?cursor=0` 逐页建立摘要库。保存 `next_cursor`，持续接收修改和撤回；遇到 withdraw 删除本地文章记录。需要正文时再取详情。

普通列表适合浏览，变更接口适合追踪更新。返回的是当前公开状态，不是所有历史正文快照。

## 4. 品牌资料观察与 AI 回答报告

建立自己的品牌项目。资料观察回答“目前有哪些公开原文证据、缺少哪些内容”；模型采样回答“这个模型对这组问题实际说了什么、有没有提到我的品牌”。

两种结果独立展示。首版资料观察需要实际读取原文并核验引用；模型采样使用 DeepSeek 模型 API，不冒充各家消费端产品的排名。

使用 `/geo/projects`、`/geo/quotes`、`/geo/checks` 和已购回答查询。

## 5. 服务商为客户提供周度监测

先为品牌选定问题与目标、确认单次报价，再授权每周计划及月预算。你可以把已有结果做成客户报告，并通过账单核对每个项目的支出。

创建计划需要 `geo:schedule` 独立授权。品牌资料、价格、目标或权限变化可能暂停计划，需要重新确认。报告比较应保持模型、题组和口径一致。
