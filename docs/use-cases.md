# GEO 观察业务场景

## 1. 品牌资料观察与 AI 回答报告

建立自己的品牌项目。资料观察回答“目前有哪些公开原文证据、缺少哪些内容”；模型采样回答“这个模型对这组问题实际说了什么、有没有提到或推荐我的品牌”。

两种结果独立展示。公开资料观察需要实际读取原文并核验引用；模型采样使用指定模型 API，不冒充各家消费端产品的排名。

使用 `/geo/projects`、`/geo/quotes`、`/geo/checks` 和已购回答、来源及历史查询接口。

## 2. 服务商为客户提供周度监测

先为品牌选定问题与目标、确认单次报价，再授权每周计划及月预算。你可以把已有结果做成客户报告，并通过账单核对每个项目的支出。

创建计划需要 `geo:schedule` 独立授权。品牌资料、价格、目标或权限变化可能暂停计划，需要重新确认。报告比较应保持模型、题组和口径一致。

以上为可接入场景，不代表当前已向所有账号开放。请查看[当前状态](status.md)后[申请接入](https://camcat.net/developers)。
