# 价格与扣费

这是首版预览规则。正式服务开放前请先确认可用性，开放后以服务端价目表和报价为准。

## 必须有余额才能使用付费业务

余额属于你的 ScopeAI 账户。付费接口同时校验账户、密钥权限、产品开放状态、预算及可用余额。新闻余额不足返回 402；GEO 余额不足不会创建收费任务或冻结。下载客户端示例不会获得免费服务额度。

当前通过账户页联系客服充值，管理员核实实际收款后入账。服务端不会因为 API 调用直接扣你的银行卡或微信；它扣的是已充值的站内余额。

| 服务 | 金额 | 规则 |
| --- | --- | --- |
| 新闻列表、搜索、热门、专题、同步 | ¥0.01 / 非空成功请求 | 每页最多 50 条 |
| 新闻正文详情 | ¥0.01 / 成功请求 | 与摘要页分开计费 |
| 资料观察 | ¥1.00 / 完整交付轮次 | 未达交付条件整轮不收费 |
| 模型回答采样 | ¥1.00 / 成功单元 | 单元 = 一道问题 × 一次重复 |
| 监测计划 | 按实际服务 | 另需计划授权与月预算 |

新闻空页、错误、纯撤回页和 304 不新增收费。免费余额、报价和已有结果查询不会再运行付费任务。模型的有效回答即使没有提到你的品牌，仍正常收费；明确服务错误、空回答和拒绝不计成功。

## 算给你看

- 100 条摘要分两页读取：0.02 元。再读其中 10 篇正文：0.10 元，合计 0.12 元。
- 20 道问题各采样一次：先冻结 20 元。18 次成功、2 次失败：扣 18 元，释放 2 元。
- 20 道问题每周一次：每轮最多 20 元。自然月可能有 4 或 5 次，按计划月预算控制，不默认一个月只有四周。

## 预算与重复请求

账户与每个 key 均可设置 0–100 元日预算，账户预算由所有 key 共用；冻结占用预算。计划另设月预算，最高 1000 元。日/月边界按北京时间计算，GEO 使用接受任务所属的预算日/月。

提交任务前先获取报价。接受报价时客户端提交最高金额，服务端不能超过它。报价有效 15 分钟，项目或目标变化需要重新报价。

为每次业务操作保存一个请求编号。网络失败时使用原编号、原参数重试；不要自动换新编号。同一单元仅结算一次。新闻可恢复响应保留 24 小时；过期或内容改变后不再返回旧内容，也不重复收费。

## 账单、取消与退回

账户页显示可用、冻结和资金流水。取消 GEO 任务会释放尚未交付部分，已经成功交付的单元保留消费。服务费争议通过客服核对原交易处理，退回作为新增流水保留记录。

未消费充值现金退回采用人工核实流程，系统不自动向微信或银行付款。请通过[官方账户页](https://camcat.net/account/billing)咨询。
