# 常见问题

**这个仓库是免费的 API 吗？**

仓库公开 GEO 观察接入资料和示例。托管分析服务采用预付费，付费业务需要充值余额及消费权限。账户查询和读取已有结果不额外收费。

**下载代码后能自己部署整套服务吗？**

不能。本仓库只含客户端及公开契约，不含分析引擎、客户数据、支付和运营后台。

**GEO 观察是不是所有 AI 平台的真实数据？**

不是。公开资料观察使用公开证据；首版真实采样来自 DeepSeek 模型 API，搜索关闭。它与网页或 App 的真实用户界面体验不等同。

**为什么必须有 API key 和余额？**

key 关联你的账户及权限，服务端据此处理预算和账单。余额不足的付费请求无法执行，修改本地示例不能改变服务端规则。

**能自助微信、支付宝或银行卡充值吗？**

当前是客服协助充值、核实后入账。没有公布自助支付能力；先在账户页确认服务开放和充值方式。

**超时会重复扣钱吗？**

同一请求编号和参数重试不会再产生一笔相同消费。请保存编号，勿在网络重试中生成新编号。GEO 本地等待超时也不会自动取消服务器任务。

**可以把 key 放在网页前端吗？**

请放在你的服务端环境变量或密钥管理工具里，由你的后端调用。浏览器中的凭据可能被访问页面的人看到。

**现在就能正式商用接入吗？**

目前是接入预览与申请开通阶段，请先查看[开放状态](status.md)，再联系官方确认；不要把契约发布当作所有生产接口已上线。
