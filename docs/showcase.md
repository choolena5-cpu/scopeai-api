## 案例与 API 的关系

网站案例展示的是品牌观察的业务价值。首版付费 API 提供公开资料观察及指定模型回答采样，两者独立报价；**首版采样使用 DeepSeek 模型 API，搜索关闭**，与本案例联网运行条件不同，不应直接比较或承诺复现分数。

本仓库未发布客户账户、项目访问凭据、完整私有报告、服务端分析或计费代码。案例图不会授予付费 API 的使用权限。[了解接入与付费](getting-started.md)
